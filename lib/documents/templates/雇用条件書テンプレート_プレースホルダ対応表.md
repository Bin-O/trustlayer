## 0. 実装上の前提（Claude Code 向け）

- **デリミタは `{{ }}`（Mustache形式）**。ライブラリのデフォルトと異なる場合は設定で合わせること。
  - `docxtemplater` は既定が `{ }` → `delimiters: { start: '{{', end: '}}' }` を指定
  - `docx-templates` は既定が `+++` → `cmdDelimiter: ['{{','}}']` を指定
- **本テンプレートのレイアウトは公式ファイルそのもの**。罫線・フォント・段組みを一切変更しないこと。
  差し込み以外の目的で `document.xml` を編集してはならない。
- **チェックボックス（`cb_` 接頭辞）は文字を差し込む方式**。値は `☑`（選択）または `□`（非選択）の
  いずれかの文字列を渡す。boolean を渡さないこと。
- **値が無い項目は空文字 `''` を渡す**。`undefined` はライブラリによって `undefined` と印字される。
- **今回の対象範囲は 本体 + 別紙1 のみ**。**別紙2（無期雇用契約用）はテンプレートから削除済み**。
  無期転換に該当するケースが実際に発生した時点で、別紙2付きの第2テンプレートを別途作成する
  （条件分岐をテンプレート内に書くのではなく、生成時にファイルを選ぶ方式とする。
  ライブラリ選定に依存しないため）。
  なお別紙2は「無期転換**後**の労働条件」を記載するものであり、本体の値をそのまま
  流用してはならない（賃金・就業場所等が異なり得る）。専用のプレースホルダ群が必要。

## 11. 検証済み事項

- 現実的なサンプルデータ差し込み後: **5ページ**（本体3＋別紙1の2）
  ※公式原本7ページのうち、別紙2の2ページ分を削除しているため
- 末尾に余白ページ・空段落の残留なし（レンダリング確認済み）
- 罫線・フォント・段組み: 公式ファイルをそのまま使用しているため同一
- OOXML スキーマ検証: PASS（`validate.py --original` にて公式ファイルとの差分ベースで確認）

> ⚠ 値が極端に長い場合（例：所在地が非常に長い等）はセル内で折り返しが発生する。
> これは公式様式でも手書き時に起こる現象であり、テンプレートの欠陥ではないが、
> 実データ投入後の目視確認を推奨する。
